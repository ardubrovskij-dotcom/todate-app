# TO DATE — картотека свиданий для пар Петербурга

Интерактивный MVP-прототип мини-приложения (Telegram mini-app / мобильное веб-приложение): электронная картотека идей для свиданий с механикой «намёк о свидании».

## Что внутри

- **Лендинг** — описание продукта, тест механики «намёк о свидании» (письмо-намёк с секретным бонусом), тарифы, «заметки на полях»
- **Онбординг** — регистрация (имя + e-mail) и приглашение половинки с предпросмотром письма-приглашения
- **Сторона партнёра** (`#/accept`) — экран по ссылке из письма: письмо-приглашение, преимущества, мини-регистрация, экран «Вы в паре!»
- **Каталог** — колода карточек + сетка идей по 4 категориям: дома, еда, отдых, релакс
- **Карточка идеи** — длительность, цена, метро, описание, избранное
- **Намёк о свидании** — форма отправки письма партнёру (e-mail, чекбокс согласия)
- **Мои намёки** — лента отправленных намёков со статусами «Отправлен» / «Услышан»
- **Избранное** — веер любимых карт + фильтры по категориям
- **Маршруты** — карта с точками, избранные и все маршруты по районам (Петроградка, Васильевский, Центральный, Коломна), карточка маршрута с точками
- **События недели** — афиша с фильтрами
- **Профиль и подписка** — неделя / месяц / 3 месяца (демо-оплата, в боевой версии — Продамус или ЮKassa)
- **Заметки на полях** — платные объявления (демо)

Данные, избранное, намёки и подписка хранятся локально в `localStorage` — без бэкенда. Прямые ссылки на экраны работают через hash: `#/home`, `#/idea/molot-vedm`, `#/routes` и т.д.

## Стек

React + TypeScript + Vite + Tailwind. Дизайн-токены (цвета, радиусы, отступы, типографика Bebas Neue / Inter) — по гайдлайну бренда.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

Деплой на GitHub Pages: собрать `npm run build` и выложить содержимое `dist/` в ветку `gh-pages` (base уже настроен на относительные пути).

## Статус

MVP-прототип для тестирования гипотезы. Не реализовано: реальная отправка писем, оплата, регистрация, бэкенд.
